Connect your GitHub

It takes about a minute. Your token never leaves your browser.

1Get a token
Create token on GitHub

Opens GitHub with the repo scope already selected. Pick an expiration, click Generate token, then copy it.

2Paste it here
3Storage repository

All your drives live in this one repository (each drive is a branch). It is created as a private repository if it doesn't exist yet. You can keep the default.

Using a fine-grained token?

Create the storage repository on GitHub first and give the token Contents: Read and write on it, then enter its name above. To let Drivemu create the repository for you, give the token access to All repositories with Administration and Contents set to Read & write.
